Petunjuk Penggunaan
1. Atur Lokasi
Ketik alamat di kolom atau tekan ikon target untuk GPS. Anda juga bisa menekan langsung di peta untuk menandai lokasi.

2. Edit Lokasi
Tahan dan geser penanda (marker) di peta untuk mengubah posisi dengan lebih akurat.

3. Titik Antar (Opsional)
Tekan "Tambah Titik Antar" untuk menambah perhentian di antara lokasi awal dan tujuan.

4. Harga
Ubah harga per km sesuai kebutuhan. Default: Rp 4.000/km.

Catatan: Jarak dihitung berdasarkan rute jalan (bukan garis lurus) menggunakan OpenStreetMap.

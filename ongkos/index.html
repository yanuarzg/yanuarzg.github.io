Cek Ongkos Om Yanu

Web kalkulator ongkos untuk antar jemput, delivery, dan belanja. Pilih titik awal dan tujuan, lihat estimasi jarak serta biaya, lalu lanjutkan pemesanan melalui WhatsApp.

Tarif awalMulai Rp 10.000
Jarak dasarHingga 3 km
LayananAntar Jemput, Delivery, Belanja
AreaArea operasional lokal

Cara menggunakan kalkulator ongkos

  • Pilih titik awal melalui pencarian, GPS, atau tandai langsung di peta.
  • Tambahkan satu atau beberapa tujuan sesuai kebutuhan.
  • Pilih jenis layanan dan aktifkan pulang-pergi bila diperlukan.
  • Lihat estimasi jarak dan ongkos sebelum memesan.

Pertanyaan umum

Bagaimana ongkos dihitung?

Perjalanan sampai batas jarak dasar memakai ongkos minimal. Di atas batas tersebut, estimasi dihitung dari jarak rute dikalikan tarif per kilometer, dengan ongkos minimal tetap berlaku.

Apakah jarak mengikuti jalan?

Ya. Aplikasi mencoba menghitung rute kendaraan melalui layanan routing. Bila server rute tidak tersedia, aplikasi menampilkan pemberitahuan dan memakai estimasi cadangan.

Apakah bisa multi tujuan dan pulang-pergi?

Bisa. Anda dapat menambah beberapa tujuan, menukar titik awal dan akhir, serta mengaktifkan mode pulang-pergi.
